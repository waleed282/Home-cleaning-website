Home Cleaning Service Website Frontend

This is a responsive frontend for a home cleaning service website, designed to provide a clean, modern, and user-friendly interface. The website is tailored for clients who want to showcase their home cleaning services online, with emphasis on luxury, convenience, and professionalism.

Features

Responsive Design: Works seamlessly on desktops, tablets, and mobile devices.

Hero Section: Attractive header with call-to-action buttons for booking and free quotes.

About Section: Highlights the company’s services and philosophy.

Services Section: Detailed cards for Regular Home Cleaning, Deep Cleaning, and Custom Cleaning Plans.

Team Section: Showcases professional cleaning staff and encourages joining the team.

Testimonials Section: Displays client feedback to build trust.

Blog/Insights Section: Expert cleaning tips and lifestyle insights.

Footer: Quick links, contact information, and social media integration.

Technologies Used

HTML5

CSS3

JavaScript 

Responsive layout using Flexbox/Grid

Images and icons for modern UI

How to Use
